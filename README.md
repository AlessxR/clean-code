# A Mini-Course on Clean Code in JavaScript

A short, practical course on writing clearer and more maintainable JavaScript. The examples compare less effective and more effective approaches to naming, working with objects and classes, testing, asynchronous code, and error handling.

## Contents

1. [`variables.js`](./variables.js) — meaningful names, constants, consistent vocabulary, explanatory variables, and named values instead of “magic numbers.”
2. [`formatting-and-comments.js`](./formatting-and-comments.js) — consistent naming conventions for variables, functions, classes, and constants.
3. [`objects.js`](./objects.js) — encapsulating object state, access methods, and hiding internal data.
4. [`classes.js`](./classes.js) — method chaining and preferring composition over inheritance.
5. [`solid.js`](./solid.js) — the five SOLID principles: Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, and Dependency Inversion.
6. [`testing-concurrency-error-handling.js`](./testing-concurrency-error-handling.js) — test structure, promises and `async`/`await`, and explicit error handling.
